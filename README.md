# NovaPlay Gaming — Demo

NovaPlay is a browser-playable virtual-credit gaming demo with Roulette, Dice, Blackjack, Slots, a virtual wallet, history, daily demo bonus, and admin demo controls.

This repository is deployed as a **play-money demo only**. It does not provide real-money deposits, cash-out, or real-money wagering.

## Deploy

Render start command: `node server.js`

The app uses browser `localStorage` for demo persistence.

## Production note

A lawful real-money gambling product requires jurisdiction-specific licensing and compliance plus audited game randomness, server-side accounting, age/KYC/AML controls, responsible-gaming controls, fraud/risk systems, approved payment processing, security testing, and legal review. Do not turn this demo into a cash-gambling system by simply adding payment endpoints.
